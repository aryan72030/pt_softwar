Module 11 – Report Generation
The system automatically generates the following reports after the statistical evaluation is completed: Individual Participant PT Report
o One report for each participating laboratory.
o Includes Participant Details, PT Program, Sample ID, Submitted Results, Assigned Values, Parameter-wise ZScores, Performance Status, Graphs, Remarks, QR Code, and Digital Signature.  Parameter-wise Z-Score Report
o One separate report is generated for each test parameter in the PT program.
o Displays the Submitted Result, Assigned Value, Z-Score, and Performance Status of all participatinglaboratories for that specific parameter.  Master Z-Score Report
o One consolidated report containing all participants and all parameters. o Used for comparing the performance of all laboratories in a single report.
